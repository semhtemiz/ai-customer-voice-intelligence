# Yerel veri

[Women’s E-Commerce Clothing Reviews](https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews) CSV’sini burada `Womens Clothing E-Commerce Reviews.csv` adıyla tutun. Kaynak başlıksız indeks kolonunu koruyun.

Ham dosya ve hesaplanan DB repository’de dağıtılmaz. `profile.json` toplulaştırılmış checksum/kayıt/KPI kontrolüdür; müşteri yorum metni içermez. Kaynak CC0 metadata’sı ve atıflar `../THIRD_PARTY_NOTICES.md` içindedir.
